# Tonex Song Advisor v0.3

Conseille le meilleur preset de votre bibliothèque TONEX pour une chanson, et la meilleure
combinaison bloc capturé (stomp + ampli) + baffle — en local, puis croisé entre plusieurs IA.

## Installation

| Fichier | Usage |
|---|---|
| `TonexSongAdvisor-0.3-setup.exe` | **Installation** par utilisateur, sans droits administrateur : raccourcis menu Démarrer et bureau, entrée « Ajout ou suppression de programmes » avec désinstallation. |
| `TonexSongAdvisor-0.3-portable.zip` | **Portable** : décompresser et lancer `TonexAdvisor.App.exe`, rien n'est installé. |

Windows 10/11 x64. Aucune installation de .NET nécessaire : les deux formats sont autonomes.

> **Exécution non signée** : les exécutables ne sont pas signés (pas de certificat de signature de
> code) — Windows SmartScreen affiche « Application non reconnue » : « Plus d'infos » puis
> « Exécuter quand même ».

## Ce que contient v0.3

- **Avis croisés multi-IA** : OpenCode (référence) et, selon les clés que vous renseignez,
  Gemini, Mistral et Groq. Les voix répondent indépendamment, un arbitre relève leurs
  contradictions et classe les 3 meilleures propositions avec leur niveau de consensus.
- **Conseil local** : classement de la bibliothèque en quelques millisecondes, hors ligne, avec
  l'explication de chaque point. La règle TONEX est respectée : le stomp et l'ampli d'une capture
  sont inséparables, seul le baffle se change (et il est toujours présenté comme remplaçable).
- **Persistance** des filtres et de l'onglet actif, icône d'application, tri par colonne.
- **Fiabilité** : test d'intégrité automatisé (empreintes SHA-256 des deux bases vérifiées
  avant/après), CI GitHub Actions, publication autonome vérifiée.
- **Manuel utilisateur illustré** dans le README.

## Garantie lecture seule

L'application **n'écrit jamais** dans les bases TONEX : connexion `Mode=ReadOnly`,
`PRAGMA query_only=ON`, filtrage des instructions SQL, et empreintes SHA-256 vérifiées par les
tests. Elle n'ouvre jamais votre dossier `Documents\IK Multimedia\TONEX` : seules les copies
`db\Library.db` et `db\Library2.db` du projet sont lues.

## Clés IA

Aucune clé n'est incluse : renseignez les vôtres dans **Bases & réglages** (OpenCode, Gemini,
Mistral, Groq) — les liens pour les demander sont dans le README. Une clé absente = une voix
silencieuse, le conseil reste valable.
