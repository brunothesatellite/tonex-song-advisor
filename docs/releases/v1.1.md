# Tonex Song Advisor v1.1

Conseille le meilleur preset de votre bibliothèque TONEX pour une chanson, la meilleure
combinaison bloc capturé (stomp + ampli) + baffle, puis croise les avis de plusieurs IA avant un
verdict arbitré.

## Installation

| Fichier | Usage |
|---|---|
| `TonexSongAdvisor-1.1-setup.exe` | **Installation** par utilisateur, sans droits administrateur : raccourcis menu Démarrer et bureau, entrée « Ajout ou suppression de programmes » avec désinstallation. |
| `TonexSongAdvisor-1.1-portable.zip` | **Portable** : décompresser et lancer `TonexAdvisor.App.exe`, rien n'est installé. |

Windows 10/11 x64, aucune installation de .NET nécessaire.

> **Exécution non signée** : les exécutables ne sont pas signés — Windows SmartScreen affiche
> « Application non reconnue » : « Plus d'infos » puis « Exécuter quand même ».

## Nouveautés de la v1.1

- **Réglages des potards en génération 2** (Phase 7) : la génération 2 ne stocke aucune valeur de
  potard — elles sont chiffrées dans les fichiers `.txp` d'IK. Quand une bibliothèque V1 est à
  côté (comme chez la plupart d'entre vous), les valeurs sont désormais **jointes
  automatiquement** : 2 313 presets enrichis sur la bibliothèque d'exemple, avec la mention
  honnête de leur origine dans le panneau de détail. Les presets présents seulement en V2
  (~200) restent sans réglage.
- **Choix de la bibliothèque** : deux façons dans « Bases & réglages » — le **chemin manuel**
  (comme avant), ou la case « Utiliser une base du dossier TONEX » avec la **liste des bases du
  dossier officiel** (trouvé par le *Known Folder* « Documents », correct même quand Documents
  est redirigé vers OneDrive). Case cochée : le chemin est grisé et la base choisie se charge ;
  décochée : le chemin reprend et sa base est rechargée. Le choix est mémorisé.
- **Correctifs** : le mode TONEX n'écrase plus le chemin du choix 1 ; les deux écrans n'effacent
  plus mutuellement leurs préférences dans `state.json`.

## Ce que contient v1.0 (toujours là)

- Lecture **strictement en lecture seule** des bibliothèques TONEX V1 et V2 : navigateur, tri,
  filtres mémorisés, panneau de détail avec potentiomètres.
- **Conseil local** expliqué, hors ligne, en quelques millisecondes.
- **Avis croisés** : OpenCode et les voix renseignées (Gemini, Mistral, Groq) choisissent dans le
  catalogue de vos blocs et baffles, avec leur **conseil libre**, puis un **verdict arbitré par
  OpenCode**.
- Installeur maison (aucun outil tiers), version portable, CI, 169 tests.

## Garantie lecture seule

L'application **n'écrit jamais** dans les bases TONEX : `Mode=ReadOnly`, `PRAGMA query_only=ON`,
filtrage des instructions SQL, empreintes SHA-256 vérifiées par les tests — et la jointe V1 se
fait **en mémoire**, sans rien modifier. Elle n'ouvre jamais votre dossier
`Documents\IK Multimedia\TONEX` en écriture.

## Clés IA

Aucune clé n'est incluse : renseignez les vôtres dans **Bases & réglages** (OpenCode, Gemini,
Mistral, Groq) — les liens pour les demander sont dans le README. Une clé absente = une voix
silencieuse, le conseil reste valable.
